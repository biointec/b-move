# Benchmark scripts for AMB
This folder contains the scripts used for benchmarking the tools on the datasets described in the AMB special issue submission. 

The [`RunBenchmarks.sh`](RunBenchmarks.sh) script is the main entry point for running the benchmarks. It orchestrates the execution of the different tools and collects the results.

The [`AggregateChrom19.sh`](AggregateChrom19.sh) script is used to aggregate the results from the chromosome 19 pan-genome benchmarks. It processes the output files generated by the tools and summarizes the performance metrics.

The [`AggregateEColi.sh`](AggregateEColi.sh) script is used to aggregate the results from the E. coli benchmarks. Similar to the chromosome 19 script, it processes the output files and summarizes the performance metrics.
